## 这套文风是什么

以《九州缥缈录》《龙族》《天之炽》三部共 350.5 万有效汉字为语料，提炼出的可迁移写作技法。

**它提炼的是技法，不是气质**。学的是句法组织、视角纪律、情绪怎么获得意义、场景怎么改判断。**不学的是它的伤感底色**，那是作者的个人选择，不是技法。

> 判断这份档案能不能用在你的项目上，看「适用与不适用」一节。它和轻松搞笑、爽文、本格推理是**冲突**的。

**三条执行原则**：

1. **不要把「江南式」简化成碎短句**。各组都以中长句承担主要信息，短句只在转折、判决、反应处获得力量。
2. **不要把早期合并成一种风格**。校园依赖回望与日常落差，九州依赖因果转折、正式语域和身体动作。
3. **不要把后期长句当作冗长**。后期延展常用于职业、制度、记忆限定和关系解释；删掉内部转折才会变松散。

## 二、五条写作基因

这五条是跨三书稳定出现的核心，也是这套文风真正的价值所在。

1. **小人物面对大世界**：宏大结构通过一个脆弱、孤独或不被承认的人显影。
2. **青春轻响与命运重击**：先写笑话、课堂、朋友和日常，再让失去变得不可回避。
3. **强画面近景**：用颜色、光源、位置、声音和动作组成可运动镜头。
4. **名字与记忆抵抗死亡**：人物是否被记住、如何被称呼、谁还记得承诺，比抽象死亡更重要。
5. **关系推动史诗**：家族、朋友、爱与忠诚决定人物如何面对战争、组织和权力。

## 三、句法骨架（五种，用于关键节拍）

**只用于少数预先选定的关键节拍，不是逐段模板**。同一场景默认选一种作为峰值，其余段落按因果自然组织；不要为了覆盖全部骨架而制造材料。

### 1. 事实，修正，真相

```
表面判断 → 但是/其实/只是等限定 → 更具体的证据 → 简短落点
```

让修正带来新信息。若「但是」前后只是同义反复，删掉转折。

### 2. 抬高，拆低，保留真心

先让人物用历史、电影、神话、理论或英雄叙事理解处境，再用钱、饭、迟到、衣服、工作、身体反应等日常事实拆低，最后让行动证明那份真心仍然有效。

**不要把拆低写成纯粹嘲笑**。落差的作用是防止自我陶醉，不是否定情感。

### 3. 清单，缺项，判决

列出一个生活、装备、手续或记忆清单，在末尾暴露唯一缺失的人、物或选择，再用短句结束。

清单必须建立秩序；缺项必须改变意义。**不要为了节奏堆无关名词**。

### 4. 机制，后果，私人代价

先说明机器、制度、军阵、血统或规则怎样运作，再把机制落到身体、空间或关系后果，最后指出谁为此失去什么。

技术说明若没有后果，压缩；私人代价若没有机制支撑，容易变成空喊。

### 5. 回忆，反事实，不可逆

先重现一个具体习惯，再写人物曾经假设的未来，最后让现实证明那个未来已经关闭。

**只在角色拥有后来视点时使用回望**。不要机械添加「多年以后」制造怀旧。

### 有效节拍

```
功能句 → 扩展句 → 修正句 → 短落点
```

**不要每段都复制同一节拍**。相邻段至少改变一种主功能：观察、解释、判断、动作或回声。允许节拍跨越多个段落。

**警惕线性微句链**：连续五六句都以人物、物件或时间起句，依次交代一个动作和一个感官结果，却没有真实转折。此时不要轮换主语或补环境，而是**合并同一判断的句子，恢复限定、因果和修正，删掉无后果的镜头**。

## 四、语域落差（这套文风最独特的一点）

从三层语域中按场景**选两层作为主轴**，第三层只在转折处出现：

| 层 | 内容 |
|---|---|
| **日常层** | 饭钱、交通、衣物、短信、课堂、工作、身体不适、社交尴尬 |
| **制度/技术层** | 职位、程序、参数、兵制、机械、医学、商业、组织规则 |
| **历史/神话层** | 王朝、宗教、传说、命运、史书、宏大身份 |

**让语域碰撞承担具体作用**：

- 日常层**拆解**宏大自我想象
- 技术层把奇观变得**可信**并制造代价
- 历史层**扩大**一项私人选择的回声
- 日常层在宏大事件后**恢复**人的尺度

**不要在一段中同时堆满品牌、专名、典故、参数和神话**。语域越多，主动作越容易消失。

## 五、叙述者姿态（按时期分五种）

| 姿态 | 做法 |
|---|---|
| **校园回望** | 亲近人物，又对其自我想象保持轻微距离。先理解那时为何认真，再由后来经验指出当时不知道的部分 |
| **九州史笔** | 先用正式、历史或礼制语言建立秩序，再下降到**手、伤口、呼吸、脚步、火光**。让宏大秩序最终由肉身承担 |
| **龙族中期** | 允许口语判断、自我纠正、夸张想象和现实拆台快速相邻。可以懂人物的丢脸，**不要替人物乞怜** |
| **天之炽** | 用较有权威感的说明句承载机械、教义、等级和城市奇观，再以年轻身体和私人承诺刺穿权威语气 |
| **后期重构** | 允许职业化解释、限定语、反问、补充和记忆矛盾进入长句。可以显得会分析，但**必须承认判断的局限** |

## 六、情绪引擎（文青写法的核心）

**把「文青写法」定义为情绪认知系统，不等同于抒情、悲伤、雨天或文化典故。**

> 核心在于：**人物用一个比现实更漂亮的解释保护真心，现实纠正这个解释，但人物仍愿意为其中真实的部分行动。**

原则：**保持「真诚受反讽保护」**：人物可以嘲笑自己的宏大想象，却不能因此逃掉选择。

### 七步诊断地图

**用于事后检查，不要直接按它生成提纲。**

1. **普通伤口**：一次具体的落选、迟到、丢脸、无人回应、被遗忘或脆弱日常
2. **防御面具**：开玩笑、讲道理、保持专业、装作不在乎、忙于实务
3. **情绪载体**：能储存共同经历的物件、季节、地点、习惯、食物、消息或文化作品
4. **借来的解释**：用故事、未来想象、神话、电影式场面或私人比喻解释伤口
5. **现实纠偏**：让时间、身份、职责、记忆差异或他人的自由选择否定解释中幼稚的部分
6. **小而昂贵的行动**：保护、等待、放手、返回、守约或替人承担，却无法保证被看见
7. **可选变义回声**：只有载体自然再现且改变选择时才返回。**不需要为了完整而回收**

**普通场景只显露真正需要的少数关系**。章级回报即使自然包含七步，也只把其中两三步写明，其余交给前文和读者推断。**不要故意让七步在结尾汇合**。

### 选择伤口（只选一个）

- 没有被选择
- 有用，却不被爱
- 一直在场，却没有被记住
- 终于赶到，但已经太迟
- 爱的人把未来给了别处
- 获得能力时，原本需要它的时机已过去
- 发现共同记忆只属于自己，或记忆本身并不可靠
- 得到英雄位置，却必须交出最普通的愿望

### 配一个补偿幻想

- 以惊人的方式出现，让所有人终于看见
- 在未来重逢时说出当年没说的话
- 相信坚持会像某个故事那样得到回报
- 以宏大身份为普通羞耻赋予意义
- 拥有一顿饭、一个家、一条消息或一项共同习惯，证明自己属于某处
- 成为某个人、承诺或消失往事的唯一保存者

**让现实部分兑现幻想的真实内核，同时拒绝它幼稚的形式**。人物可以变得重要，却没有掌声；可以救下对方，却没有被选择；可以保存记忆，却不能恢复过去。

### 现实纠偏不能只是「命运残酷」

选一种**可观察力量**：

| 类型 | 内容 |
|---|---|
| 时间 | 毕业、错过班次、疾病进展、季节过去、消息迟到 |
| 身份 | 阶层、职务、家族、婚姻、阵营、社会礼节 |
| 职责 | 任务、照护、战争、工作、债务、对第三人的承诺 |
| 记忆 | 两人对同一往事记得不同，记录给出第三种版本 |
| 他人意志 | 对方**真诚地**选择另一种未来，不是被反派强迫 |
| 身体 | 能力、伤病、年龄或距离使想象无法照原样发生 |

**纠偏后必须保留选择空间**。若人物只能被动受苦，情绪不会转化为人格。

### 强度校准

| 档 | 做法 |
|---|---|
| **0 关闭** | 直接写类型叙事，不主动运行文青引擎 |
| **1 纹理** | 用一项自然存在的日常事实和轻度落差，不为完成等级专门新增载体 |
| **2 潜台词** | 从伤口、面具、载体、纠偏、行动中选三至四项，不追求闭环 |
| **3 完整** | 章节序列具备真实伤口、纠偏和行动，单场只明写必要两三项 |
| **4 峰值** | 允许一次密集回忆、自我追问或悲剧性抬高，**仅用于章级回报** |

**不要让 4 级覆盖整章**。必须先有普通生活的跑道，峰值后写后果。爱情线也不要把 2-4 级设为常驻。连续的低强度亲密、笑话、合作、争执和修复本身就是关系内容。

### 正负对照

**正例**：人物没被邀请参加庆祝，却被拜托保管钥匙。散场后他发现对方忘了带药，绕路送去，只把药交给门卫；第二天照常归还钥匙，没有解释自己为什么迟到。

> 有效，因为事件和选择已经暴露在乎，正文没再把钥匙变成象征，也没补写格言、独处远景或第二次情绪收束。

**伪文青**：人物站在雨里想起许多名著和旧歌，感叹青春、孤独、命运与爱情，随后什么也没有选择，关系也没有改变。

> 无效，因为意象和典故替代了伤口、阻力和行动。

## 七、场景与描写

### 描写的五步语法（诊断用，非生成顺序）

```
坐标 → 主导感官 → 变化 → 解释 → 后果
```

先写普通因果稿；只有读者无法定位、无法形成预测或无法理解后果时，才补足对应环节。

一场通常只需**开端建立一次坐标，关键变化处更新一次模型**。若连续两段只有坐标和主导感官，没有变化与后果，合并或删除。

### 叙事 ≠ 描写

- **叙事**改变人物、关系、风险、知识或选择
- **描写**改变读者对位置、气氛、人物或事物的模型

一处描写要服务于：定位、预告、揭性格、增加压力、建立可信度或制造变义回声。**普通连续性细节可以只维持时间、动作和空间，不必独立象征**。

### 空间与感官

**一场只设一个主通道、一个副通道**：

| 通道 | 适合 |
|---|---|
| 光色 | 可见性、仪式、城市奇观、身份差异 |
| 声音 | 距离、接近、空旷、机械、不可见危险 |
| 温度 | 身体压力、内外边界、记忆反差 |
| 材质 | 机械、武器、建筑、损伤可信度 |
| 身体 | 近景代价与心理外化 |
| 气味味觉 | 生活残留、场所身份、突发记忆 |

**不要把六种感官全部点名。感官越多不等于画面越清楚。**

主通道已经两次承担重要功能后，后续同类光、声、温度或材质**只在改变行动条件时出现**。

持续维护三个空间关系：**前景/背景、内部/外部、人物/出口**。移动发生后，更新至少一个关系。

### 环境与氛围

先确定**环境对人物做什么**：遮蔽、暴露、隔离、引导、压迫、诱惑或延迟。

```
空间边界 → 主导感官 → 可移动因素 → 人物应对 → 新风险
```

让天气作用于**路线、能见度、衣物、机械、声音或社交选择**。天气若不改变任何条件，只保留一个最短标记。

让光线说明**权力与可见性**：谁在亮处被观看，谁在暗处观察，什么东西反光或吞没光线。**不要把颜色当作无功能滤镜**。

### 人物出场

**先写人物改变了什么，再写人物长什么样。**

有效出场可改变：房间里的声音 / 他人站位或目光 / 门口道路退路 / 规则执行方式 / 某个物件的归属 / 视点人物的预测。

选择**两到三个**身体证据：姿态、手、步幅、呼吸、伤处、衣物受力、与物件的关系。**不要从头发到鞋逐项扫描**。

### 间接心理描写

**不要先写「他很悲伤」**。按顺序外化：

1. 人物正在完成的实用动作
2. 动作中一个**不必要的重复、停顿或纠正**
3. 人物对物件、空间或他人的**错误关注**
4. 与真实需要**相反的口头解释**
5. 必须选择时暴露的**优先级**

**心理描写应改变行动模型**。若内心段落结束后人物的预测、决定和关系都未改变，缩短它。

### 物件与奇观

```
用途印象 → 一个可测细节 → 运作规则 → 异常 → 身体/关系后果
```

先让读者知道「它会怎样影响人」，再补名称与历史。**只保留能改变预测的参数**。

为复杂机制选一个统领性类比，且类比要**来自视点人物的经验**。不要在同段更换三套比喻。

奇观必须与尺寸、声音、温度、材料或运动建立至少一项可验证联系，随后立即回答：**人物现在能做什么、不能做什么？**

## 八、信息释放与留白

维护四个信息集合：

- 视点人物知道什么
- 其他人物知道什么
- 读者已可合理推断什么
- 本场故意暂缓什么

### 解释设定前问三句

1. 人物为什么**此刻**注意它？
2. 它怎样改变**预测或选择**？
3. 保留效果所需的**最短具体形式**是什么？

### 让强揭示「重分类」前文，而不是否定前文

- 无害物件 → 可被重分类为工具、证据或威胁
- 礼貌动作 → 可被重分类为试探
- 失败 → 可被重分类为筛选

**不要依靠读者不可能看见的事实制造转折**。关键证据应先以普通细节出现。

### 留白纪律

使用留白前**先明确省略对象**。可以暂缓：完整动机、关系命名、时间过程、世界答案、中心事件、远期后果。

**不能省略**：理解当下选择所需的因果、空间、身份和风险。

视点必须有不知道、不愿承认、无暇解释或无权得知的**理由**。

> **留白扣住的是最终判断，不是基本叙事义务。**
> **缺失因果不是留白。**

---

## 九、章节结构与收尾

### 四种转场

- **共享物件**：同一物件换了持有者或意义
- **因果切**：先展示后果，再回到原因
- **对照切**：从仪式到代价、胜利到伤者、笑话到独处
- **时间压缩**：只概括决定和不可逆变化，在下一压力点重新入场

### 区分「场景交接」与「章节终止」

**内部场景**以直接硬切或新目标、新压力、新事实接管为主。

**全章只选一个终止效果**，成立后立即停止：

- 一项选择关闭了退路
- 一个意象改变了意义
- 一个答案被延迟但更紧迫
- 一段关系被重新分类
- 一个实际动作承载未说出的真相
- 一个空间边界被跨越或永久关闭

**把「停止」当作硬动作**：圈出最早成立的出口，默认删除其后所有只重复情绪的离场、路程、灯光、车窗、食物和独处镜头。

**核心纪律**：类型钩子已经成立时，不要再追加完整的归家、夜路、食物或天气余韵。

## 十、失效清单（这些是伪特征）

以下写法**看起来像江南，实际不是**：

- 无因由地叠加雨、黄昏、火焰、铁、海、星空
- 把每个动作都写成「仿佛某种命运」
- 用连续反问代替证据
- 让所有段落都有可摘抄的格言
- 改写原作著名句式，只替换名词
- 堆砌雨、奢侈品、神话、音乐、校园笑话、长篇演讲、格言来制造「江南感」
- 让每个细节都象征、每段都漂亮收尾、每场都完成情绪引擎
- **天气、音乐、比喻、显性认知和物件回声全部表演同一种情绪**
- 把所有线索都写成神秘信号，把所有留白都留到结尾
- 不分场景地给每段都套「动作、感官、解释、比喻、判决」
- 让物理运动冒充叙事运动（风、发丝、纸角、灰尘、脚步、倒影、光影只有在紧邻一拍改变了可达性、风险、判断或选择时才算数）
- 把「画面漂亮」误当叙事有效

## 十一、适用与不适用（重要）

### 适合

- 青春校园、都市幻想、史诗奇幻、历史战争
- 关系推进型故事、离别与重逢、成长与失去
- 需要「余味」而非「爽感」的章节

### 不适合（会互相破坏）

| 项目类型 | 冲突点 |
|---|---|
| **轻松搞笑 / 日常轻巧** | 本档案的情绪引擎建立在「失去、错过、代价」上，与轻巧基调相反 |
| **强爽文 / 快速升级** | 本档案要求高潮由人物选择触发，不由外部奇观或突发巧合 |
| **本格推理 / 硬科幻** | 强度应降到「轻度」，只保留近景视角与选择代价 |
| **高对话轻小说** | 本档案句长 27-33 字、短句率仅 22-28%，与「短句率 45%+」冲突 |
| **明确禁氛围描写的项目** | 本档案环境与氛围是核心模块，直接冲突 |

### 强度自动降档

出现以下任一情况，**降低一级**：

- 用户强调本格、硬核、写实、轻松、快速升级或平台节奏
- 原项目已有明确第一人称、冷硬、极简或喜剧文风
- 文风意象开始压过线索、规则、爽点或现实事务
- 角色说话趋同，所有人都像在发表告别感言

### 局部浓度

**同一章可以按场景调节**：日常轻度，冲突标准，高潮浓郁，余波重新降到轻度。**不要让整章持续高音**。

## 十二、调用方式

本档案**默认不生效**。项目要用时在 `lorebook/风格卡.md` 或 `文风模仿要求.md` 里显式声明：

```markdown
- **风格来源**：江南式文风档案（`references/style-jiangnan.md`）
- **采用强度**：标准 / 轻度 / 浓郁
- **采用模块**：语域落差 + 情绪引擎 + 场景收尾
- **明确不采用**：比喻密度（本作禁比喻）、氛围描写（本作禁氛围）
```

**只采用显式声明的模块**。未声明的部分不生效。

### 三条硬边界

1. **不复制、轻度改写、重组或延伸可识别的原句**
2. **不导入原作的情节本体、角色关系几何、身份冲突、力量体系或牺牲偏好**。只迁移表达与情绪技法
3. **不声称输出是原作者所写、经其授权或与其无法区分**

### 使用后需自检

- [ ] 是否把「江南感」做成了雨+奢侈品+神话+格言的堆砌？
- [ ] 每个重要节拍是否只有一个主比喻？
- [ ] 比喻是否属于当前观察者的知识背景？
- [ ] 是否连续以「他/她/人物名」开句？
- [ ] 是否每段都有完整节拍和漂亮段尾？（若是，释放功能段）
- [ ] 清晰动作或比喻之后是否又解释了一遍？
- [ ] 高潮之后是否出现了第二、第三次收尾？
- [ ] 是否出现了来源作品的专名、标志性意象组合或可识别句骨？
- [ ] 删去最漂亮的一句后，场景因果是否仍然成立？

**最后一条是总检验**：删去最漂亮的一句，场景还成立吗？不成立就先补因果。
