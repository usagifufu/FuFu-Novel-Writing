# 活人感写作接入指南（human-writing 融合版）

来源项目：[KKKKhazix/human-writing](https://github.com/KKKKhazix/human-writing) v1.1.0（MIT）。
让 AI 写的中文读起来像一个具体的人在说话。本技能将其方法论与检测脚本融入写作流水线的 **起草与润色** 环节，与 `aigc_detect.py` 互补分工。

## 与 aigc_detect.py 的分工

| 工具 | 查什么 | 何时用 |
|---|---|---|
| `aigc_detect.py`（AIGC 痕迹） | AI 指纹：行内重复、平衡句/"连…都"、比喻密度、句首代词密度、高频复读 | 检测"像不像 AI 写的"（外部检测前的自检） |
| `check_prose.py`（硬禁令） | 翻案腔（含变形）、排比≥3、名词化、冒号滥用、破折号、黑话、模型路标、抒情词、句长节奏 | 成稿后清"绝对不能出现的东西"（交稿前的硬门槛） |
| `novel_lint.py`（静态扫描） | 填充词、机械过渡、公式化设问、句式雷同 | 常规质量扫描 |

三者按序跑：`novel_lint.py`（常规）→ `aigc_detect.py`（AI 指纹）→ `check_prose.py`（硬禁令清零后才能交稿）。

## 快速开始

```bash
cd scripts
python check_prose.py 稿件.md          # 硬禁令检查（失败项 + 需人工判断项）
```

输出分两类：
- **需要修改**：硬禁令命中（冒号滥用、破折号、黑话等），必须清零。
- **需要人工判断**：翻案腔变形、排比、抒情词、路标等——先立误解再推翻就改，正常用法保留。

实测（一篇 2589 字中文小说稿）：冒号 4 处（第 3/4/78/160 行）+ 疑似翻案腔变形 1 处（第 48 行"不是…，是…"句式）。

## 核心方法论（写入起草阶段）

### 七遍改稿法（references/human-writing/references/revision.md）

1. **看谁在说**：叙述者凭什么知道、在哪在意、哪段换模型也能写出来（优先处理）。
2. **看文章怎样往前走**：每段标作用，后段必须新增东西，删注水。
3. **拆表演性中文**：假深刻/假具体/假口语/抽象名词/比喻换场。
4. **听中文顺不顺**：主干早点来、前句交给后句、停顿有轻重、动作后少解释、白话古意不打架。
5. **清禁用项**（见下）。
6. **核现实或设定**：事实/时间/数字/因果；虚构核人物知道什么。
7. **查结尾**：最后两段删掉再读；禁末段重新概括全文；禁升华到时代/文明/全人类。

### 硬禁令（check_prose.py 强制执行）

- 禁破折号（—、——、–）——与 D-009 一致
- 冒号只允许引出人物直接原话，禁"一句话总结："式提示冒号
- 禁翻案腔（按**动作**查，不只查字面）：不是A而是B/并非A而是B/与其说A不如说B/表面…实际…/看似…实则…/你以为…其实…/回头才发现/说到底/答案恰恰相反/A不重要重要的是B 及一切变形
- 禁三项以上同构排比（两项为限）
- 不给抽象名词配具体动词抒情（时间不会保管细节、焦虑不会显出形状）
- 动词不名词化（"完成了对流程的优化"→"把流程改顺了"）
- 禁"说白了/说穿了/先说结论"
- 禁模型路标（更微妙的是/还有一层/只说对了一半/值得注意的是/需要指出的是/从某种意义上说）
- 禁商业黑话（赋能/抓手/闭环/底层逻辑/顶层设计/拉通/颗粒度/降本增效…，完整清单见脚本与 revision.md）

> 与既有约束的关系：本套禁令与 `lorebook/风格卡.md`、`写作约束.md`、D-009（禁破折号）、D-010（减文学性）同源，可作为它们的**可执行版本**——风格卡管方向，check_prose.py 管落地。

## 在流水线中的位置

- **起草阶段**：参照 fiction.md 的人物目标/对白做事/细节跟视角写正文（与"场景靠物件+动作+对话呈现"一致）。
- **步骤 5 润色与 Anti-AI 终检**：`novel_lint.py` → `aigc_detect.py` → `check_prose.py` 依次跑；`check_prose.py` 失败项必须清零，人工判断项由 AI 结合语境复核，不静默改写。

> 铁律：检测是找候选位置，不是判决。是否修改由作者拍板，AI 不静默改写。
