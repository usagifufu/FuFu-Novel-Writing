# 文风学习（Style Learning）

用途：用户提供样本文件（自己以前的稿子、喜欢的作者文本、平台范文），从中提取可执行、可引用的**文风档案**，供每章 Writer Brief 引用。

## 何时使用

- 新项目开写前：定义本书的文风基调。
- 用户说"按我给的文本风格写""学一下这个作者的文风"。
- 用户说"下载 XX 小说学文风""学一下番茄小说的文风"：先走 [novel-download.md](novel-download.md) 的下载流程获取平台范文，再按本流程分析。
- 写了几章后感觉文风漂移，需要校准。
- 多份样本（不同作者/不同功能文本）需要合成单一风格。

## 流程

1. **收集样本**：1-3 个文件，建议每个不少于 2000 字；标注来源与用途（作者本人 / 模仿对象 / 平台要求）；确认版权边界（只提取特征，不复制句子）。没有现成样本时，可用番茄小说下载器获取平台范文（见 [novel-download.md](novel-download.md)），下载后先跑 `scripts/prepare_samples.py <下载目录或文件> -o 风格资料/sources` 整理成干净语料（剥 HTML、滤广告、统计字数/章节数），再进入下一步。
2. **统计分析**：跑 `scripts/style_analyze.py <样本文件>...` 得到量化特征（句长、段落、标点、对话密度、高频双字、语气词、句式）。
3. **语境提炼**：通读样本，按六个维度归纳：
   - **词汇层**：高频词、特色词、口头禅、语气词、称谓习惯。
   - **句式层**：句长偏好、标点习惯、设问/反问/排比使用频率。
   - **描写层**：动作/环境/心理/外貌的描写比例，感官通道偏好（视觉/听觉/嗅觉/触觉）。
   - **对话层**：对话密度、对话标签用法（说道/问/省略）、人物语气差异。
   - **节奏层**：段落长短、场景切换频率、章节收尾方式（钩子/余韵/总结）。
   - **叙述层**：视角、人称、叙述距离（贴近心理 vs 冷静旁观）。
4. **三层风格链建档**（多份样本必走，单份也推荐）：
   - **Source pack（拆书笔记）**：每个样本的原始分析记录——出处、字数、逐维度特征与证据片段（只记特征描述，不抄长句）。
   - **Manifest（风格清单）**：从 source 提炼的可执行规则列表，含量化参数（句长、对话密度）与质化偏好。
   - **Composed（风格说明书）**：多源合成后的单一风格卡，写入 `lorebook/风格卡.md`。
5. **多源合成**：主来源定基调，其他来源只补充可融合的特征；冲突特征（如一个短句流、一个长句流）显式取舍并记录理由；合成后不再逐份引用样本。
6. **试写校准**：按风格卡试写 300-500 字，与样本对比，让用户确认哪些特征保留、加强、去掉。
7. **定稿入档**：风格卡存档后，每章 Brief 引用；使用中若发现"不像"，回到第 2-3 步重新统计校准。

## 风格卡字段

与 [writer-brief.md](writer-brief.md) 保持一致：

```markdown
## 风格卡：<名称/用途>
- 来源样本：<文件、出处、字数>
- 基调：热血 / 轻松 / 压抑 / 冷峻 / 古风 / 现代……
- 句长：平均 X 字，短句率 Y%（来自统计）
- 段落：平均 Z 字，短段落占比（来自统计）
- 描写密度：动作优先 / 氛围优先 / 心理优先；感官偏好
- 对话：密度 W%，标签用法，人物语气差异
- 用词：高频特色词、口头禅、语气词、避免的词
- 句式习惯：设问/排比/反问的使用强度
- 节奏：快（短场景连击）/ 慢（细节铺陈）；收尾方式
- 叙述：视角、人称、叙述距离
- 合成取舍：多源冲突特征怎么定的（如有）
- 禁学特征：样本中不想继承的缺点
```

## 三层风格链的目录落地

单文件场景直接在 `lorebook/风格卡.md` 内分区维护；项目复杂时：

```text
风格资料/
├── sources/      # 拆书笔记/样本原始分析（每条注明出处与字数）
├── manifest/     # 风格清单（可执行规则 + 量化参数）
└── composed/     # 风格说明书（最终风格卡，Brief 只引用这一层）
```

规则：Brief 永远引用 composed 层；manifest 只在合成或校准重跑时读；sources 只在重做分析时读。

## 边界与禁忌

- **学特征不抄句子**：风格卡只写规则和统计特征；样本句子不得原样搬进正文。
- **版权**：样本是他人作品时仅做特征学习，输出不得包含样本原文片段；文档里注明出处。
- **区分文风与文笔**：节奏、用词、密度可学；天赋性的文笔质感只能近似，不能机械复刻。
- **多档案**：不同视角人物、不同卷可以有各自风格卡，分开建档。
- **反面特征**：样本里的缺点（冗余、烂尾习惯）默认不学；用户要求保留才写入。
- **改动留痕**：修改风格卡时在 `plot/decisions.md` 记录原因。
