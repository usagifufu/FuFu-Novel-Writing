## 第一部分 核心信念与指令语气

### 1.1 核心信念

AI 味的主要问题不是语法错误，而是**过度圆滑、工整、解释充分**。改写目标：保留剧情功能，增加口语、停顿、跳跃和具体动作。

1. **改味优先，别当改错**。AI 味是风格问题，不是语法错误。
2. **改最少，效果最大**。能改一个词就不改一句，能删一句就不重写一段。
3. **只改"怎么说"，不改"说什么"**。剧情、人设、情节走向一概不动。
4. **保留有功能的语气**（质问 `？`、爆发峰值少量 `！`），不保留破折号。

### 1.2 指令语气

本清单以问题模式和高危清单为主。一级高危词优先检查；二级或语境敏感词按频率、语境、是否偷懒判断。遇到冲突时，**保留创作意图与剧情功能优先于机械替换**。

### 1.3 静态扫描与语境复核的分工

1. **静态扫描**：秒级扫全稿，给出稳定可复现的候选位置，它只是证据，不是判决。
2. **语境复核**：同一个句式在爽文里是节奏，在文艺向里是滥用。命中不等于要改，结合上下文判定。
3. **修复边界**：能机械改的（纯填充词）可直接改；需要语境判断的先给候选和计划，展示后再动稿。
4. **改后复查**：事实、视角、承诺是否在修改中被破坏。

## 第二部分 写作约束（始终生效）

### 2.1 活人感写作规范

**应遵循**

1. 使用白描手法，禁止比喻、拟人等修辞。
2. 使用口语化、平实朴素的句式，力求易于理解。
3. 使用直接、具体的描述，避免冗长的形容词堆砌和空洞的抽象概念。
4. 不因上述原则省略句子成分（主语、谓语、宾语、定语、状语、补语），成分缺失会让句子生硬机械化。
5. 禁止把结构完整的句子拆成多个零碎的句子，保持句子完整性。
6. 以"画面感"为核心，采用多样化的感官描写表现既视感。
7. 时刻推进剧情，确保情节紧凑、逻辑连贯。
8. 多使用完整、连贯、自然的对白推动剧情。
9. 以高质量中文网络小说的风格作为基准。
10. 留有适度的悬念与伏笔作为钩子，钩子可下一章回收，也可留待后续展开。

**应避免**

1. 不承认那些不确定性或复杂的感受。
2. 硬套模板，而没有幽默、没有锋芒、没有个性。
3. 描写细微、难以察觉或根本不存在的细节元素，如"拂去肩膀上不存在的灰尘"。
4. 使文字死板，读起来像新闻稿而非故事。
5. 过度使用书面用语、成语或文艺化表述。
6. 使用不承担任何有效功能的华丽或文艺辞藻。
7. 过度省略连接词、过渡句、形容词而导致句子、段落机械化。连接词如：那、了、则、还、也、着、但是、然后、随之、以及、不过。
8. 依据刻板印象理解和塑造人物。
9. 使用夹叙夹议的写作方法。
10. 绝对禁止任何括号、破折号这类解释性格式。

**多样化**

1. 避免重复使用相同的句式、词汇和结构。
2. 通过多样的叙事视角、时间顺序和情节推进方式保持读者好奇。
3. 禁止重复前文出现过的台词、情节和桥段。

**反例与修改对照**

| 反例 | 修改 | 问题 |
|---|---|---|
| 他想动，手脚不听使唤。 | 他想动，但是手脚却不听使唤。 | 过度省略连接词 |
| 不是错觉。 | 那不是错觉。 | 缺乏主语 |
| 走廊很静。 | 走廊很安静。 | 过度简化 |
| 他最近健身，确实累。 | 他最近在健身，确实会比较累。 | 生硬、不完整的对白 |

### 2.2 用户自定义硬约束（禁写事项，全书默认生效）

**禁止句式与比喻**

- 绝对避免"这句话像是投入平静湖面的巨石"这类句型。
- 强制禁止用于比喻或明喻的词：火山、心湖、油锅、石子、湖面、针刺、羽毛、重锤、掀起、巨浪、泛起、涟漪、惊雷、某种、水中、波澜、水滴、炸弹。

**禁止浅薄或程式化的情绪暗示与直述**

- 禁止"眼神闪过""眼底闪烁某某情绪""带着 xx 意味""带着某种""不再是某某而是带着某某""带着一种""并没有立刻"。

**禁止惰性或模糊的情绪状态描述**

- 禁止直接陈述"声音平淡，没有太多情绪"这类写法。
- 禁止"近乎某某情绪状态""充满了某种"。

**禁止滥用或俗套的生理与动作细节**

- 禁止"指节描写与动作""嘴角弧度""审视"。

**禁止惰性、抽象或无意义的状态描述**

- 禁止"不容拒绝""不易察觉""难以察觉""不可置信""不容置疑"。

**禁止动物比喻与平衡句式**

- 禁止动物比喻"像一只某某"。
- 严禁"不是某某而是某某""不仅某某更是某某"等平衡句式。需要表达转折，把一段话分成两段说。

**补充类目**

| 类别 | 替代原则 |
|---|---|
| 抽象升华词（命运、宿命、注定） | 用具体事件代替抽象概念 |
| 万能比喻（像潮水般、如闪电般、仿佛春风） | 要么不用，要么用生活化的比喻 |

### 2.3 禁用词表

**一级（出现即替换）**

- **情态类**：仿佛、犹如、宛若、如同、一丝、一抹、些许、几分、隐约
- **动作类**：深吸一口气、缓缓、不禁、微微、轻轻、淡淡
- **表情类**：眼中闪过、嘴角勾起、眉头微皱、眉眼低垂、瞳孔微缩
- **心理类**：心中一动、心头一震、心下了然、心中暗道、心底泛起、不由得
- **判断类**：不容置疑、不容置喙、不易察觉、显而易见、毫无疑问、不可否认
- **形容类**：坚定、闪烁着光芒、狡黠、深邃、凛冽、冰冷
- **过渡类**：不由自主、情不自禁、自然而然

**二级（高频或偷懒时才处理）**

- **语境敏感词**：突然、好像、瞬间。角色口语、真实突发、时间压缩、视角不确定时可保留。
- **总结句式**：他这才意识到、他终于明白、此刻他、一切都、原来是
- **排比句式**：连续 3 句以上同构排比；有的某某有的某某；一边某某一边某某
- **升华句式**：这一刻、他知道、她明白、这就是

**填充词与冗余修饰（llmlint 类）**

- 高频弱化词：不禁、仿佛、似乎、好像、宛如、犹如、顿时、瞬间、缓缓、轻轻、微微、深深、默默、喃喃、忽然、蓦然
- 高频表情包式写法：嘴角、眼底、眸光、眼神、目光连用、心中一动、心头一紧

**机械过渡与套路衔接**

然而、不过、就在这时、只见、没想到、令人惊讶的是、原来如此、可想而知、不知不觉、不得不说、实际上、毕竟

**空泛总结与万金油结尾**

总而言之、总的来说、这一刻、仿佛一切、一切仿佛、岁月静好、一切都结束了、新的开始、眼神坚定地望向远方、嘴角勾起一抹笑

**书面腔转口语化对照**

| 书面腔 | 口语化 |
|---|---|
| 瓦解 | 消失 / 散了 / 没了 |
| 无名火 | 烦躁 |
| 往我心上捅刀子 | 心烦意乱 |
| 不容置疑 | 就是 |

### 2.4 最毒禁用句式（出现即修，最高优先级）

| 毒级 | 句式 | 错误例 | 修法 |
|---|---|---|---|
| ★★★★★ | 不是 A，是 B / 不是 A，不是 B，是 C。含省略连接词与跨句换行变体 | 他不是冷漠，而是绝望 | 直接写 B 或换更自然的表达 |
| ★★★★ | "，带着某某"万能状语 | 他笑了一下，带着一丝不易察觉的嘲讽 | 拆短句或换动作 |
| ★★★★ | "声音不大，却带着一种某某的力量" | 她声音不大，却带着不容置疑的力量 | 直接写声音特征或动作 |
| ★★★★ | "他某某知道某某" | 他知道这一切都来不及了 | 用行为展示认知 |
| ★★★ | "仿佛某某一般" | 仿佛能穿透一切一般 | 删掉或白描 |
| ★★★ | "眼中闪过一丝某某""嘴角勾起一抹某某" | 眼中闪过一丝悲伤 | 他垂下眼 / 他笑了一下，没到眼底 |
| ★★★ | "心中涌起一股某某""心头一震" | 心中涌起一股暖流 | 用身体反应 |
| ★★ | 章末预告"他不知道的是某某" | 他不知道的是，更大的风暴即将来临 | 用具体钩子物件或事件收束 |

> 命中 ★★★★★ 一处即视为重度 AI 味强证据；★★★★ 命中 2 处及以上触发中度复扫。

**公式化设问（补充分类）**

"难道某某吗""是不是某某""为什么某某"后接空泛回答或留白，连续出现形成套路。修法：删掉自问自答，让答案从情节、动作或对话里长出来。

### 2.5 八种 AI 写作模式检测

**模式 1：AI 高频词**。不禁、仿佛、映入眼帘、心中暗道、沉声道、脸色一变、嘴角微扬、不由自主、只见、此时此刻、目光如炬。删或换动作。

**模式 2：弱化副词泛滥**。每千字超过 3 个即 AI 签名。重点监控：微微、淡淡、缓缓、轻轻。

**模式 3：意义膨胀**。"意义深远"改写成具体后果；"前所未有"给对比参照；"可谓"直接删。

**模式 4：万能结论**。"未来可期"改用未解决的紧张感结尾；"前途无量"删；"充满希望"写具体的下一步动作。

**模式 5：论文体段落结构**。出现即 AI 入侵：不难看出、由此可见、事实上、综上所述。

**模式 6：书面语连词泛滥**。于是乎、与此同时、从而、因而、诚然。口语化替代或删除。

**模式 7：三连排比癖**。AI 喜欢把事情凑成三个显完整。砍到只剩最有力的一条。

**模式 8：解释腔、上帝视角、安排感**。最难察觉、最像 AI。

| 表现 | 处理 |
|---|---|
| 解释因果："之所以某某是因为""原来""这意味着""正是因为" | 删。因果从角色动作、对话、反应里让读者自己拼 |
| 上帝视角剧透：她不知道的是、殊不知、多年以后、冥冥之中、仿佛预示着 | 删。只写角色此刻知道的 |
| 替读者下结论：演得真好、这出戏她看过一遍、他就是这样薄情的人 | 删。证据摆出来，定性留给读者 |
| 替角色总结心理：她明白，这一切都是命 | 换成一句带偏见的闪念或一个身体反应 |
| 安排感与硬铺垫：为后文强行交代背景、整段回忆倒叙 | 背景按角色此刻真实所需，用闪念、半句话、物件零碎带出 |
| 升华式收尾：结尾对仗拔高、金句点题 | 用一个动作或一句留白收住 |
| 评判性副词与补语：关切得恰到好处、笑得恰如其分、不多不少 | 只写动作，装不装让读者自己判 |
| 剧透式点破潜台词：那点笑她看得分明、谁都看得出他在撒谎 | 留着别点破 |
| 定性比喻与盖棺句：像在宣判一件早已定好的事、像看一件死物 | 非角色此刻强烈主观感受就删 |

> 自检：每句问一遍，这是"角色在经历"，还是"作者在讲解或安排"？凡作者跳出来讲，删或改成角色视角内的呈现。根治办法：锁死深度限知视角，镜头钉在角色身体里。
>
> **删解释腔不等于把读者读懵**：新名词、新设定首次出现，要让读者抓到一个锚，靠角色动作反应、对话半句自然提及或场景物理后果一笔带出作用与分量。既不整段讲来历，也别甩零信息生词。例：储物装置首次出现不写"这是储存记忆的装置"，但可写她把装置按上太阳穴、记忆碎片炸开在眼前。

### 2.6 格式与叙事红线

**正文格式硬规**

1. 段落按戏剧单元、镜头、一件事结束自然断开。不按固定字数强拆，也不把多个动作、线索、视线切换塞进一段。
2. 正文相邻段落间只允许一个换行符，不得出现空行。
3. 禁止"他说""她道"标签堆砌，对话用动作引出或独立成行。
4. 禁止大段描写堆砌，描写穿插动作或对话，不连续超过 3 段纯描写。
5. 禁止跳出视角，锁死主视角后不切他人内心。
6. 禁止主语过密。同一动作链内不要连续句或段重复同一主角名；段首点名，段中用代词或省略承接，关键转折再点名。
7. 正文禁用破折号、双连字符、括号。省略号可用，用于对话停顿与语意未尽。
8. 标题行以外不得出现写作元信息词：第几章、上一章、上章、前一章、本章、这一章、前文、后文、伏笔、细纲、读者。需要承接前文就改成角色能感知的事件锚点或相对时间。

**叙事红线**

1. 禁止章末总结、升华、哲理收尾。
2. 禁止"他感到""他觉得"直述情绪，用身体反应替代。
3. 禁止连续 2 段以上纯心理活动，必须穿插动作或对话。
4. 禁止万能比喻，要么不用要么生活化。
5. 禁止所有角色说话方式一样，每个角色必须有独立语言风格。
6. 对话三功能检验：每段对话删掉后检查，情节还能推进吗、期待感还在吗、情绪还到位吗。三项全否等于水字数，删。

## 第三部分 AI 指纹与检测维度

### 3.1 行级指纹

| 指纹 | 示例 | 触发标准 |
|---|---|---|
| 行内短语重复 | 没了、都没有 | 同一行内短语重复出现 |
| 平衡句 | 不是 A 而是 B、既某某又某某 | 出现即标记 |
| "连某某都"句式 | 连想馋都馋不起来 | 出现即标记 |
| 多重"的"修饰 | 他眼底的深邃的沉静的暗色 | 一行内"的"出现 4 次及以上 |
| 因果链句式 | 因为某某所以某某、正因如此 | 堆叠出现 |
| 比喻堆砌 | 一行内多个像、仿佛、如同 | 出现即标记 |
| 空泛总结 | 这就是生活、一切都会好的 | 出现即标记 |
| 正式表达 | 然而、与此同时、显而易见 | 出现即标记 |
| 行过长 | 无断句长行 | 单行超过 80 字 |

### 3.2 全文级指纹

| 指纹 | 触发标准 |
|---|---|
| 比喻密度 | 全文比喻 3 个及以上告警 |
| 句首代词密度 | 连续行句首"他、她、我"密度过高 |
| 高频二字词复读 | 同一二字词全文出现 8 次及以上 |
| 高频四字短语复读 | 同一四字短语全文高频出现 |
| 三连排比 | 三个并列形容词、分句或意象扎堆 |

### 3.3 段尾环境描写（隐蔽指纹，专章）

**机制**：AI 生成段落时需要收束信号，而环境句是最廉价的情绪封口。风、光、影、夜色不需要逻辑推进就能让一段话显得完整。人类作者段末收在动作、对话或具体念头上，AI 收在氛围上。所以只禁"抒情"不够，必须禁"段尾位置"。

**提示词写法**

```
段末禁用环境描写收尾。一句话结束前，必须停在以下三种东西之一：
1. 一个动作。他按下开关，灯没亮。
2. 一句对话或心理活动原话。别回头，他对自己说。
3. 一个具体的念头或判断。他确定这屋里不止他一个人。
禁止用风、光、影、夜色、声响、空气、灰尘这类句子给段落做情绪落点。
```

**准入条件（防换皮，必须一起给）**

```
环境描写全篇只允许出现在三种情况，且只能放段中或段首，禁止放段尾：
1. 它直接改变角色下一步动作。雨突然大了，他得找地方躲。
2. 它携带新信息，制造判断或悬念。墙上的钟停在三点，他明明四点才进门。
3. 它作为转场的第一句，不是收尾句。
判定标准：写完每段，删掉最后一句环境描写，如果情节或情绪零损失，说明它在偷懒，必须删。
```

**反例对照**

| AI 典型段尾 | 人类改法 |
|---|---|
| 他关了灯。黑暗里，风呜呜地刮着，树叶沙沙响。 | 他关了灯。走廊那头传来脚步声，越来越近。 |
| 她走了。阳光透过窗帘洒进来，尘埃在光柱里飞舞。 | 她走了。他数到三，才把举了一半的手放下。 |
| 他攥紧拳头，没有说话。窗外的雨下了一夜。 | 他攥紧拳头，没说话，把那张纸折了四折塞进兜里。 |
| 战斗结束了。硝烟散去，夕阳把大地染成金色。 | 战斗结束了。他蹲下来，把队友的铭牌捡起来擦干净。 |

注意：**带信息的环境或声音句不算违规**（第一行改法就是声音句），它推动了"谁来了"的判断。要区分"氛围"和"信息"。

**自查**：逐段取最后一句，若为天气、光线、景物、声响、空气的描写，且删掉后情节与情绪零损失，即重写段尾。

### 3.4 叠加式描写（同一动作掰开写三遍）

**检测模式**：一个动作或情绪先写发生，再补感知细节，再补身体反应，分三段依次写完。读者看到的是同一个动作被掰开写了三遍。

**典型特征**

- 先写概括性动作，再展开写同一动作的细节，再写身体反应。三段说的是同一件事。
- 发生层、感知层、反应层按顺序分段出现。
- 每个维度独立成段，而不是揉进同一段连续正文。

**错误示例**

> 林父低着头，左手把文书压住，右手拿笔，往纸上落。
>
> 手从肘到腕都在抖。
>
> 笔尖在纸上停了停，写了一横，又停。那个林字的撇写歪了。

**正确做法**：发生、感知、反应三个维度揉进同一段连续正文。

> 林父左手压着文书，右手拿笔往纸上落，笔尖一触纸面就偏了，从肘到腕止不住地抖，那一横斜着拖出去。

### 3.5 AI 味打分客观指标

| 指标 | 计算方式 | 轻度 | 中度 | 重度 |
|---|---|---|---|---|
| 禁用词密度 | 命中次数每千字 | ≤5 | 6 到 15 | >15 |
| 连续排比段数 | 连续同构句式段落数 | ≤2 | 3 到 4 | ≥5 |
| 心理词占比 | 直接心理描写词数除以总段落数 | ≤10% | 10% 到 25% | >25% |
| 对话标签密度 | 说道、问道、笑道等除以对话句数 | ≤30% | 30% 到 50% | >50% |
| 平均段落句数 | 总句数除以总段落数 | ≤3 | 3 到 5 | >5 |
| 重复描写密度 | 同一信息、动作、情绪连续多段拆写处数每千字 | ≤1 | 2 到 3 | ≥4 |

综合判定取六项最高档。轻度只过 Gate A 加 B；中度过 A 加 B 加 C 加 D 加 G；重度完整 7 Gate 加重点段落重写。

## 第四部分 改写方法论

### 4.1 七 Gate 门禁（去 AI 味执行序）

**Gate A 禁用词替换**。对照禁用词表逐项替换。规则：禁用词换成具体动作或细节，不能换成另一个形容词，用展示替代告诉。

- 眼中闪过一丝不易察觉的悲伤，改成：他垂下眼
- 深吸一口气，改成：胸口起伏了一下。或直接删，这动作九成无意义
- 嘴角勾起一抹冷笑，改成：他笑了一下，没到眼底

**Gate B 句式去套路**

- 硬禁"先否定再肯定"翻转句式，含省略连接词与跨句换行变体。直接写后项，或改成动作、细节呈现。
- "，带着某某"万能状语，改独立短句或动作。
- 对话标签公式化，用动作或上下文替代，普通"说"可保留。
- 修饰词清扫：形容词、定语、副词、指示代词、量词多余即删。白色的药片改成药片；飞驰的汽车改成汽车。一次只用一个形容词或不修饰。

**Gate C 心理描写外化**

- 他很紧张，改成：他的手在抖
- 她很愤怒，改成：她一把掀翻了桌子
- 他很害怕，改成：他的腿在发抖，几乎站不稳
- 她很伤心，改成：她转过身去，肩膀微微颤动
- 情绪词默认外化。短篇题材若要求情绪直给加焊体感，可直写情绪成语并紧跟一个身体反应焊住，只杀空泛无体感的写法。
- **重复描写去重**：同一动作被拆成"动作概述、感知细节、身体反应"三段时，合并成同一段连续画面。
- **重复语义四类**：形容词重复（兴高采烈地笑着跑过来，改成笑着跑过来）、近义词重复（非常重要的关键问题，改成关键问题）、含义重复（我好饿肚子咕咕叫，改成我好饿）、上下文主语重复（上文说把药扔了一地，下文只写药片）。

**Gate D 节奏打碎**。打断连续排比，留 1 到 2 个；长句拆短句；偶尔用不完整句制造口语感；段落长短交错，不要每段都 3 到 5 行。短不等于通篇同长度，须按情绪节拍、动作推进形成长短交错、疏密有别，沉淀放慢、冲突骤短。标点节奏跟语气走，避免通篇句号化。

**Gate E 对话去腔调**。加入口语化表达，如嗯、哦、行吧；适当打断，答非所问；用动作穿插对话；删解释性对话，角色不会把自己的动机说清楚；所有角色同一语气要差异化；质问才用问号，爆发峰值才少量感叹，犹豫、吞咽、打断、拖长用动作、短句或换行处理。

**Gate F 结尾去升华**。删总结性语句；用动作或场景收尾，不用感慨收尾；"他知道某某""这一刻某某"基本可删。

**Gate G 去解释腔与上帝感**。删一切叙述者跳出角色当下的解释、剧透、总结、定性、升华，对应模式 8 全部子项。这是说教感、上帝感、机械感、安排感的根治 Gate，靠深度限知视角落地。Gate G 删的是非故事性的作者旁白，不是删情节；删完变薄靠角色动作和对话补，不补叙述者解说。

### 4.2 系统性去 AI 三遍法

**Pass 1 去泛化（去掉八成 AI 味）**：抽象情绪总结句删或换具体动作；假深度句删；意义膨胀缩小到具体影响；空洞结论删；工整对比句式打散重写；装饰性形容词堆砌改白描；过度用"于是、然而、此刻"删一半；所有角色说话一样高级要区分语气。

**Pass 2 去书面化**：分析性用词（机制、结构、逻辑、体系出现在小说里）换日常表达；抽象名词滥用改成直接说事；体制内用语（进一步、深入、推进、落实）删；专业术语堆砌只留必要并用白话解释。
> 例外：历史题材正式用语、文学向刻意密度、喜剧夸张修辞可保留专业感。

**Pass 3 回自然感**：注入具体感官细节（气味、温度、触感）；角色说话方式区分；节奏变化（长短句交错）；社会位置感的对话（上下级说话方式不同）；场景特有的记忆点；项目特有语言习惯（口头禅）。少即是多，每段加 1 到 2 个具体细节就够。

**升级策略**：轻度只做 Pass 1；中度 Pass 1 加 2；重度完整三遍加重点段落重写。

### 4.3 Show Don't Tell 对照

| 告诉 | 展示 |
|---|---|
| 他是个胆小的人 | 他把检查报告在手里翻来覆去看了三遍，还是不敢打开 |
| 这间酒吧很吵 | 酒保凑到他耳边喊了两次他才听见 |
| 她很富有 | 她随手把一张信用卡丢在桌上，卡面上的数字比这顿饭贵十倍 |
| 两人关系很差 | 他把烟掐灭在她刚泡的茶杯里，她面无表情地把杯子推到一边 |
| 他很聪明 | 三秒钟。他看了三秒钟就把文件合上了。第三页，第二行。 |

核心方法：用行为代替形容词、用细节代替总结、用对话代替旁白、用反应代替情绪词。

### 4.4 改写范例库

**情绪外化**

| 情绪 | AI 写法 | 自然写法 |
|---|---|---|
| 紧张 | 他感到一阵紧张，心跳不由自主地加快了 | 他攥紧了手里的纸杯，水洒出来一些 |
| 愤怒 | 愤怒在他心中燃烧，他不由得握紧了拳头 | 他把筷子往桌上一拍，碗里的汤溅了出来 |
| 悲伤 | 一丝悲伤涌上心头，她的眼中闪过泪光 | 她低头搅着咖啡，搅了很久 |
| 害怕 | 恐惧瞬间笼罩了他，他感到一阵战栗 | 他的背贴在墙上，不敢动 |
| 失望 | 她感到一丝失落，心仿佛被什么东西揪住了 | 哦。她把手机锁了屏 |
| 惊讶 | 他的瞳孔微微收缩，显然没有想到会听到这样的话 | 他张了张嘴，什么都没说出来 |

**场景、天气、打斗**

- 阳光透过窗帘的缝隙洒进来，在地板上投下斑驳的光影，改成：下午三点，客厅里只有钟在走。
- 天空阴沉沉的，乌云密布，仿佛随时都会下起倾盆大雨，改成：要下雨了。风把晾在外面的衣服吹得乱晃。
- 他的拳头犹如疾风骤雨般猛烈，每一击都蕴含着不容置疑的力量，改成：他一拳怼过去，对方没躲开，嘴角破了。

**结尾**

- 他站在窗前，望着远方的天际线，终于明白了生活的真谛，改成：他把烟掐了，回屋睡觉。
- 这一刻，一切都变了。她知道，从今以后，改成：她关上了那扇门。没回头。
- 岁月如流水般悄然流逝，直接删掉。

**节奏**

- 他看着她的眼睛，看着她的嘴唇，看着她微微颤动的睫毛，改成：他看着她。她没说话。
- 当他终于推开那扇沉重的木门时，映入眼帘的是，改成：门开了。屋里很暗，角落堆着几个箱子，上头全是灰。

**冲突对话**

- AI 式温和：我觉得你这样做不太合适，能不能考虑一下我的感受。改成：你眼里还有我吗。
- AI 式完美解释：其实我这样做是有原因的，因为当时的情况非常复杂。改成：你能怎么着。她把茶杯重重放下。

**对话情绪五级递进（冲突场景从弱到强）**

1. 客观陈述：你把我的东西扔了。
2. 陈述加建议：你把我的东西扔了，以后能不能先跟我说一声。
3. 主观指责：你凭什么动我的东西。
4. 指责加命令：你算什么东西，也配碰我的东西。滚出去。
5. 指责加精神打压：我伺候你吃伺候你穿，你连个东西都放不好。你这辈子也就是这样了。

**震惊分层（禁止一步到位）**

AI 式：所有人都震惊了，不敢相信自己的耳朵。
自然分层：① 对面男人的手抖了一下，茶杯里的水洒出来。② 旁边的人互相看了一眼，有人往后退了一步，角落里有人开始掏手机。③ 刚才还趾高气扬的女人，脸上的笑僵住了，张了张嘴，一个字没说出来。

**代入感修复**

- 被动主角：她很害怕，不知道该怎么办，只能等着事情过去。
- 主动主角：她锁了门，把手机调成静音，打开了录音。

### 4.5 文体骨架化操作表（检测不过时按此由深到浅修）

> 结论：**过检测靠换骨架（文体级），不是换皮（词汇级）**。毛刺修完仍不过，病灶在文体骨架。

| 级别 | 操作 | 说明 |
|---|---|---|
| P0 | 加对话回合 | 纯独白改对话切面，让人物用对白承担信息与情绪。例：早点睡。嗯。明天降温，多穿件。嗯。 |
| P0 | 加外部切面 | 增加他人视角，打破单一主角内心独白 |
| P1 | 压缩铺陈 | 景物铺陈段落压缩六成，只留一个工作性细节 |
| P1 | 信息炸弹章末 | 章节末尾放一个炸裂信息，不用氛围收尾 |
| P2 | 毛刺清扫 | 跑完前四步后再清词汇级毛刺：比喻、连某某都、平衡句、句首代词 |

### 4.6 Sepia 三遍处理协议（叙事架构层，最深处）

**第一遍：叙事架构**（每篇只选 3 到 5 个动作，加 1 个稀有动作）

1. **主题别解释**。叙述者绝不总结教训；对话只争具体利益，不辩论抽象理念；留一个不为主题服务的闲笔场景。
2. **松开单轨因果**。打断一次因果链；留一个永远不引爆的细节；做回声测试，这桥段重生成二十次还会出现吗，会就换成本故事独有的。
3. **结局别默认"成长加接受加选择"三脚架**。这是最强的结尾指纹。一半时间让偶然、他人、机构决定结局；允许残缺、开放、灾难结局；通常早停一拍比完整收尾更好。
4. **时间非线性是选择不是默认**。适度非线性，不是五比五的极致；用时间跳切藏信息，先给果后给因；最大的披露放后面；防"前置灌输"，别在开动前把上下文全倒完。
5. **打破 show-don't-tell 教条**。AI 恐惧等于胸闷加冷汗加灯暗；人类四模式混用，行为第一、直说第二；身体感只留给 1 到 2 个峰值；气味要省。
6. **人物网络稀疏化**。主角登场用对话或动作，别用外貌加身世描写；人物网络稀疏；关系净情感近零；反派要有自己的盟友和裂痕。
7. **真实世界锚点加读者存在**。点名真实作品、地点、品牌，必须真实正确；偶尔一个承认读者存在的旁白；场景比前提需要多一两个。

**第二遍：话语流**

- **QUD 检查**：每段隐含回答一个问题；机器默认序列是场景简报、动机辩解、社会后果、责任重量。至少要一个"但那不是我姐姐记得的样子"式对照段。
- **提纲测试**：每段首句抽出来连读，如果构成全文摘要就是机器形状；人类提纲有跳、有缺、有脱离上下文读不懂的句子。
- **中段是命门**：中段至少放一个开头预测不到的事件；相邻场景纹理要交替（密与快、对话与概述）。
- **版式位置**：段落长度参差，允许一句话段落；关键台词别总在段尾；列举别总是三项；场景转场换花样。
- **开头**：从情境中间切入，别用布景式开场；一个工作性细节锚定空间即可。

**第三遍：表层风格**

- 七类编辑痕迹按频率排查：用词不当、句式破碎、冗余铺陈、陈词滥调、缺乏具体性、紫色散文、时态漂移。
- 句法模板（超出人类用法 2 到 5 倍）：抽象名词加 of 结构、现在分词的悬垂短语、名词化主语、配对抽象（留一个）、"不仅是某更是某"、排比三连。
- 禁词按**簇**算。单次命中不是判决，扎堆才改写。
- 加回人类语域：缩写、话语小品词、因果连词、模糊限制语、合成否定、同义反复的"说"反而是人类、语域允许时的粗话。
- 朗读测试：语法正确但说不出口就是 slop，改口语形状。
- 误报白名单（别修）：干净语法、单次破折号或分号、正式文体的正式语气、引语内的禁词、作者本人验证过的习惯、普通句子。

**校准三原则**

1. **瞄准中间带，不是反向极点**。人类是适度非线性，不是满分非线性。把每个 AI 特征都反转等于制造新指纹。
2. **精选不堆砌**。每篇只选 3 到 5 个动作加 1 个稀有动作，跨篇轮换。
3. **留余量**。普通句子、未展开的想法、朴素段落，别每寸都磨光。

## 第五部分 质量检查清单（写完每章逐项扫）

**语言与 AI 指纹**

- [ ] 正文无破折号、无括号
- [ ] 无 AI 高频词：不禁、仿佛、映入眼帘、心中暗道、沉声道、嘴角微扬、不由自主、只见
- [ ] 弱化副词每千字"微微、淡淡、缓缓、轻轻"不超过 3 个
- [ ] 无三连排比、无"不是 A 而是 B"翻转句式
- [ ] 无"不难看出、由此可见、事实上、综上所述"
- [ ] 无书面语连词堆砌：于是乎、与此同时、从而、因而、诚然
- [ ] 章尾无总结升华，用动作、对话或悬念收束
- [ ] 无大段心理描写，心理活动不超过 2 段
- [ ] 情绪用动作展示，无直接写愤怒、伤心、紧张
- [ ] 对话口语化，无书面腔，不同角色语气可区分
- [ ] 段尾不是环境描写收尾
- [ ] 无叠加式描写（同一动作掰开写三遍）
- [ ] Show Don't Tell：用行为代替形容词，用细节代替总结
- [ ] 句长匹配场景，打斗冲突段更短，朗读不卡、信息不过载
- [ ] 身体部位同一词全文不超过 5 次
- [ ] 无正文元信息污染（章号、上一章、伏笔、细纲、读者）

**结构与节奏**

- [ ] 开头有钩子，不是天气、风景、日常开场
- [ ] 中段有推进，局势有变化
- [ ] 结尾落在变化上，有危机、决定、发现、反转至少一个，不是总结
- [ ] 没有可删除的段落
- [ ] 没有大段设定说明文，一章新概念不超过 3 个
- [ ] 人物在做事情，不是在感觉事情
- [ ] 场景有目标、阻碍、变化三要素
- [ ] 无连续多段同一情绪

**审校执行顺序**

1. 静态扫描收集命中。
2. 逐条语境复核，分三类：删（纯填充）、改（有候选写法）、留（节奏需要，注明理由）。
3. 输出修复计划，批准后修改。
4. 修改后复查事实、视角、承诺是否被破坏。

## 第六部分 可直接粘贴的提示词模板

### 模板 A 章节写作（起笔新章节时粘贴）

```
你是一名中文网络小说作者，正在写《书名》第某章。严格遵守以下规范：

一、语感：直白口语化，拒绝书卷气。短句有打击感。场景靠物件、动作、对话呈现，禁止抒情氛围句与诗意结尾。男主必须掌控型、主动型，不吃瘪。
二、修辞：使用白描，禁止比喻、拟人。禁止"像一只某某"类动物比喻。禁止"不是某某而是某某""不仅某某更是某某"平衡句，需要转折就把话分成两段说。比喻全篇最多 3 个且必须生活化。
三、句式：口语化平实，保持句子成分完整，禁止把完整句拆成零碎句。禁止过度省略连接词、过渡句、形容词。禁止夹叙夹议。
四、标点：绝对禁止括号与破折号。对话停顿用省略号，冒号只准引人物原话。感叹号只用在爆发峰值，问号只用在质问与真实疑问。
五、情绪：禁止眼神闪过、带着某种意味、嘴角弧度、审视等程式化写法。禁止不容拒绝、不易察觉等惰性抽象词。允许直说情绪，但直说后要跟一个身体反应焊住。
六、环境：段末禁用环境描写收尾。段落必须停在动作、对话原话或具体念头上。环境句只在三种情况出现且只能放段首段中：它改变角色下一步动作、它携带新信息制造悬念、它作为转场首句。
七、结构：时刻推进剧情。每章结尾留一个钩子，可下章回收或留待展开。禁止重复前文出现过的台词、桥段、句式。章末不写总结、升华、哲理、预告。
八、视角：锁死深度限知视角。只写角色此刻看到听到闻到的，不解释因果、不剧透、不定性、不替读者下结论。
九、多样化：避免相同句式、词汇、结构重复。段落长短交错，疏密有别。
十、对照基准：以高质量中文网络小说（番茄男频）的风格为基准。
```
