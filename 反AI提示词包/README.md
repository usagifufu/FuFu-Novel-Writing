# 反 AI 提示词包

防 AI 感写作的完整资产包。用于中文网文创作：写作时注入约束、改稿时对照执行、投稿前自检、检测不过时重写。

## 包内内容

| 文件 | 说明 |
|---|---|
| `反AI提示词大全-融合版.md` | **主文档**。8 大部分 + 6 个可直接粘贴的提示词模板，两份上游文档去重融合，冲突项已裁决 |
| `分册/fufu体系版-指纹与骨架化.md` | 原 fufu 体系版。偏自定义指纹（连某某都、句首代词密度）、文体骨架化操作表、Sepia 三遍协议 |
| `分册/story-setup体系版-禁令与范例.md` | 原 story-setup 体系版。偏官方禁用词表、最毒句式星级表、7 Gate、改写范例库、打分指标 |
| `检测脚本/aigc_detect.py` | AI 指纹扫描。行级加全文级指纹，支持 `--html` 高亮报告、`--json`、`--stdin` |
| `检测脚本/check_prose.py` | 硬禁令扫描。翻案腔、冒号滥用、破折号、括号、名词化、黑话 |

## 快速上手

**起笔写新章节**：把主文档「模板 A」整段复制给模型，附上章节要求。

**改现有稿**：复制「模板 B」。

**投稿前自检**：复制「模板 C」，它会只报告不修改，按 P0、P1、P2 分级给清单。

**检测不通过**：复制「模板 D」，按文体骨架化重写。

**想让模型全程守住约束**：把「模板 E」放进系统提示词或风格卡。

**单独一段烂了**：复制「模板 F」，局部急救。

## 跑检测脚本

```bash
python 检测脚本/aigc_detect.py 稿件.md                  # 终端报告
python 检测脚本/aigc_detect.py 稿件.md --html 报告.html  # 高亮报告
python 检测脚本/check_prose.py 稿件.md                  # 硬禁令清零
```

两个脚本零依赖，纯标准库，Python 3.8 以上可直接跑。

分工是：`aigc_detect.py` 查「像不像 AI 写的」，`check_prose.py` 查「绝对不能出现的东西」。两个都过，再看 Sepia 三遍协议查叙事架构层。

## 一条重要说明

两份上游文档对省略号的口径相反，fufu 体系允许、story-setup 体系禁止。融合版已裁决为 **允许省略号，禁用破折号**，与既有写作习惯一致。若你的目标平台或编辑另有要求，改主文档第〇部分的裁决表即可。

## 两条铁律

1. **检测是找候选位置，不是判决。** 是否修改由作者拍板。
2. **改坏文比留痕更失败。** 把文章改烂而命中清零是彻底的失败。
