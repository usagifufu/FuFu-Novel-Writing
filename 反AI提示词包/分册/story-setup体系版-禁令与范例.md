# 反AI提示词全集（story-setup 体系完整版）

> 来源整合：story-setup / story-deslop 共享 agent-references（anti-ai-writing.md + banned-words.md + quality-checklist.md）+ narrative-writer 7 Gate + rules（story-narrative / story-format）。
> 用途：写作、改稿、审查、去AI味时按需整段复制给模型。

---

## 一、核心信念（放在任何提示词最前）

AI 味的主要问题不是语法错误，而是**过度圆滑、工整、解释充分**。改写目标：保留剧情功能，增加口语、停顿、跳跃和具体动作。

1. 改味优先，别当改错。AI 味是风格问题，不是语法错误。
2. 改最少，效果最大。能改一个词就不改一句，能删一句就不重写一段。
3. 只改"怎么说"，不改"说什么"。剧情、人设、情节走向一概不动。
4. 保留有功能的语气（质问 `？`、爆发峰值少量 `！`），不保留长停顿符号（`……`/`——`）。

---

## 二、自然文本基准（AI味对比表）

| 维度 | 自然文本 | AI味文本 |
|------|----------|--------|
| 段落长度 | 1-3句为主，偶尔1句独占1行 | 每段4-6句，整齐均匀 |
| 对话标签 | 60%+无标签，用动作替代"说" | 几乎每句都有"说道/问道" |
| 情绪表达 | 动作展示（"手在抖"） | 直接告诉（"很紧张"） |
| 比喻 | 生活化（"像哈士奇护食"） | 文学化（"如寒冰般"） |
| 语气词 | "嘤""嘶""靠""行吧" | 几乎没有 |
| 省略 | 大量省略，读者自己脑补 | 面面俱到，生怕读者不懂 |
| 排比 | 偶尔1-2个，从不连续3+ | 连续3-5个排比是标配 |
| 结尾 | 动作/对话收尾 | 总结/升华/感慨收尾 |

## 三、最毒禁用句式（出现即修，最高优先级）

| 毒级 | 句式 | 错误例 | 修法 |
|------|------|--------|------|
| ★★★★★ | "不是A，（而）是B" / "不是A，不是B，（而）是C"（"而"可省略，跨句/换行变体也算）| "他不是冷漠，而是绝望" | 直接写 B 或用更自然的表达 |
| ★★★★ | "，带着……" 万能状语 | "他笑了一下，带着一丝不易察觉的嘲讽" | 拆短句或换动作 |
| ★★★★ | "声音不大，却带着一种……的力量" | "她声音不大，却带着不容置疑的力量" | 直接写声音特征或动作 |
| ★★★★ | "他/她知道……" | "他知道这一切都来不及了" | 用行为展示认知 |
| ★★★ | "仿佛/犹如/宛若……一般" | "仿佛能穿透一切一般" | 删掉或白描 |
| ★★★ | "眼中闪过一丝……" / "嘴角勾起一抹……" | "眼中闪过一丝悲伤" | 他垂下眼 / 他笑了一下，没到眼底 |
| ★★★ | "心中涌起一股……" / "心头一震" | "心中涌起一股暖流" | 用身体反应 |
| ★★ | 章末预告 "他不知道的是……" | "他不知道的是，更大的风暴即将来临" | 用具体钩子物件/事件收束 |

> 凡命中 ★★★★★ 一处即视为重度AI味强证据；★★★★ 命中 ≥2 处即触发中度复扫。

## 四、一级禁用词（出现即替换）

- **情态类**：仿佛、犹如、宛若、如同、一丝、一抹、些许、几分、隐约
- **动作类**：深吸一口气、缓缓、不禁、微微、轻轻、淡淡
- **表情类**：眼中闪过、嘴角勾起、眉头微皱、眉眼低垂、瞳孔微缩
- **心理类**：心中一动、心头一震、心下了然、心中暗道、心底泛起、不由得
- **判断类**：不容置疑、不容置喙、不易察觉、显而易见、毫无疑问、不可否认
- **形容类**：坚定、闪烁着光芒、狡黠、深邃、凛冽、冰冷
- **过渡类**：不由自主、情不自禁、自然而然

## 五、二级禁用词（高频/偷懒时才处理）

- **语境敏感词**：突然、好像、瞬间（角色口语、真实突发、时间压缩、视角不确定时可保留）
- **总结句式**："他/她终于明白…"、"他/她这才意识到…"、"此刻，他/她…"、"一切…都…"、"原来…"
- **排比句式**：连续3句以上同构排比；"有的…有的…有的…"；"一边…一边…一边…"
- **升华句式**："这一刻…"、"他知道…"、"她明白…"、"这就是…"

## 六、书面腔 → 口语化对照

| 书面腔 | 口语化替换 |
|--------|-----------|
| 瓦解 | 消失 / 散了 / 没了 |
| 无名火 | 烦躁 |
| 往我心上捅刀子 | 心烦意乱 |
| 不容置疑 | 就是 |

## 七、比喻分类（默认全删）

带"像/如/仿佛/犹如/宛若"的比喻是 AI 强信号，默认全删；生活化、角色化比喻可保留。
把比喻改为直接描述/动词/名词/作用/结果/事实。例："脸色惨白得像这漫天的雪" → "脸色惨白"。

## 八、8 种 AI 写作模式检测

**模式 1：AI 高频词** — 不禁/仿佛/映入眼帘/心中暗道/沉声道/脸色一变/嘴角微扬/不由自主/只见/此时此刻/目光如炬 → 删或用动作替代。

**模式 2：弱化副词泛滥** — 每1000字超3个 = AI签名。重点监控：微微、淡淡、缓缓、轻轻。

**模式 3：意义膨胀** — "意义深远"→写具体后果；"前所未有"→给对比参照；"可谓"→删。

**模式 4：万能结论** — "未来可期"→用未解决的紧张感结尾；"前途无量"→删；"充满希望"→写具体的下一步动作。

**模式 5：论文体段落结构** — 出现即AI入侵："不难看出""由此可见""事实上""综上所述"。

**模式 6：书面语连词泛滥** — "于是乎""与此同时""从而""因而""诚然" → 口语化替代或删除。

**模式 7：三连排比癖** — AI 喜欢把事情凑成三个显"完整" → 砍到只剩最有力的一条。

**模式 8：解释腔 / 上帝视角 / 安排感（最难察觉、最像AI）**

| 表现 | 例（删/改） |
|---|---|
| 解释因果 | 「之所以…是因为」「原来…」「这意味着」「正是因为」→ 删。因果从角色动作、对话、反应里让读者自己拼 |
| 上帝视角剧透 | 「她不知道的是」「殊不知」「多年以后」「冥冥之中」「仿佛预示着」→ 删。只写角色此刻知道的 |
| 替读者下结论/定性 | 「演得真好」「这出戏她看过一遍」「他就是这样薄情的人」→ 删。证据摆出来，定性留给读者 |
| 替角色总结心理 | 「她明白，这一切都是命」→ 换成一句带偏见的闪念或一个身体反应 |
| 安排感/硬铺垫 | 为后文强行交代背景、整段回忆倒叙 → 背景按角色此刻真实所需，用闪念、半句话、物件零碎带出 |
| 升华式收尾 | 结尾对仗拔高、金句点题 → 用一个动作或一句留白收住 |
| 评判性副词/补语 | 「关切得恰到好处」「笑得恰如其分」「不多不少」→ 只写动作，装不装让读者自己判 |
| 剧透式点破潜台词 | 「那点笑她看得分明」「谁都看得出他在撒谎」→ 留着别点破 |
| 定性比喻/盖棺句 | 「像在宣判一件早已定好的事」「像看一件死物」→ 非角色此刻强烈主观感受就删 |

> 自检：每句问一遍——这是"角色在经历"，还是"作者在讲解/安排"？凡作者跳出来讲，删或改成角色视角内的呈现。根治办法：锁死深度限知视角，镜头钉在角色身体里。
>
> **但删解释腔 ≠ 把读者读懵**：新名词/新设定首次出现，要让读者抓到一个锚——靠角色动作反应、对话半句自然提及或场景物理后果，一笔带出作用与分量；既不整段讲来历，也别甩零信息生词。例：「蓝晶」首次出现不写"这是储存记忆的装置"，但可写她把蓝晶按上太阳穴、记忆碎片炸开在眼前。

## 九、7 Gate 门禁（去AI味执行序）

**Gate A 禁用词替换**：对照禁用词表逐项替换。规则：禁用词 → 具体动作/细节；不能换成另一个形容词；用"展示"替代"告诉"。
- ❌ "眼中闪过一丝不易察觉的悲伤" → ✅ "他垂下眼"
- ❌ "深吸一口气" → ✅ "胸口起伏了一下"（或直接删，这动作90%无意义）
- ❌ "嘴角勾起一抹冷笑" → ✅ "他笑了一下，没到眼底"

**Gate B 句式去套路**：
- 硬禁"先否定再肯定"翻转句式（含省略连接词、跨句/换行变体）：直接写后项，或改成动作/细节呈现
- "，带着…"万能状语 → 独立短句或动作
- 对话标签公式化 → 用动作/上下文替代，普通"说"可保留
- **修饰词清扫**：形容词/定语/副词/指示代词/量词多余即删。"白色的药片"→"药片"；"飞驰的汽车"→"汽车"。一次只用一个形容词或不修饰

**Gate C 心理描写外化**：
- "他很紧张" → "他的手在抖"
- "她很愤怒" → "她一把掀翻了桌子"
- "他很害怕" → "他的腿在发抖，几乎站不稳"
- "她很伤心" → "她转过身去，肩膀微微颤动"
- 情绪词默认外化；短篇题材包要求"情绪直给+焊体感"时：直写情绪成语（心如死灰）并紧跟一个身体反应焊住，只杀空泛无体感的（"一丝悲伤涌上心头"）
- **重复描写去重**：同一动作被拆成"动作概述→感知细节→身体反应"三段 → 合并成同一段连续画面。"他拿起笔。手在抖。笔尖又停住。" → "他拿起笔，笔尖刚碰到纸就偏了，手腕压了两次都没压稳。"
- **重复语义四类**：形容词重复（"兴高采烈地笑着跑过来"→"笑着跑过来"）；近义词重复（"非常重要的关键问题"→"关键问题"）；含义重复（"我好饿，肚子咕咕叫"→"我好饿"）；上下文主语重复（上文说"把抗抑郁药扔了一地"，下文不写"地上的抗抑郁药"，只写"药片"）

**Gate D 节奏打碎**：打断连续排比（留1-2个）；长句拆短句；偶尔用不完整句（口语感）；段落长短交错（不要每段都3-5行）；短≠通篇同长度，须按情绪 beat、动作推进形成长短交错、疏密有别，沉淀放慢、冲突骤短；标点节奏跟语气走，避免通篇句号化。

**Gate E 对话去腔调**：加入口语化表达（"嗯""哦""行吧"）；适当打断（答非所问）；用动作穿插对话；删解释性对话（角色不会把自己的动机说清楚）；所有角色同一语气 → 差异化（按语言风格档案）；质问才用问号，爆发峰值才少量感叹，犹豫/吞咽/打断/拖长用动作、短句或换行，正文不用 `……`/`——`。

**Gate F 结尾去升华**：删总结性语句；用动作/场景收尾，不用感慨收尾；"他知道…""这一刻…"基本可删。

**Gate G 去解释腔/上帝感/安排感**：删一切叙述者跳出角色当下的解释、剧透、总结、定性、升华（对应模式 8 全部子项）。这是"说教感/上帝感/机械感/安排感"的根治 Gate，靠深度限知视角落地。Gate G 删的是"非故事性的作者旁白"，不是删情节；删完变薄靠角色动作/对话补，不补叙述者解说。

## 十、系统性去AI三遍法

**Pass 1 去泛化（去80% AI味）**：抽象情绪总结句→删或换具体动作；假深度句→删；意义膨胀→缩小到具体影响；空洞结论→删；工整对比句式→打散重写；装饰性形容词堆砌→白描；过度用"于是/然而/此刻"→删一半；所有角色说话一样"高级"→区分语气。

**Pass 2 去书面化**：分析性用词（"机制""结构""逻辑""体系"出现于小说）→换日常表达；抽象名词滥用→直接说事；体制内用语（"进一步""深入""推进""落实"）→删；专业术语堆砌→只留必要，用白话解释。
> 例外：历史题材正式用语、文学向刻意密度、喜剧夸张修辞可保留专业感。

**Pass 3 回自然感**：注入具体的感官细节（气味、温度、触感）；角色说话方式区分；节奏变化（长短句交错）；社会位置感的对话（上下级说话方式不同）；场景特有的记忆点；项目特有语言习惯（口头禅）。少即是多，每段加1-2个具体细节就够。

**升级策略**：轻度只做 Pass 1；中度 Pass 1+2；重度完整三遍+重点段落重写。

## 十一、Show Don't Tell 对照表

| Tell（告诉） | Show（展示） |
|-------------|-------------|
| 他是个胆小的人 | 他把检查报告在手里翻来覆去看了三遍，还是不敢打开 |
| 这间酒吧很吵 | 酒保凑到他耳边喊了两次他才听见 |
| 她很富有 | 她随手把一张信用卡丢在桌上，卡面上的数字比这顿饭贵十倍 |
| 两人关系很差 | 他把烟掐灭在她刚泡的茶杯里，她面无表情地把杯子推到一边 |
| 他很聪明 | 三秒钟。他看了三秒钟就把文件合上了。"第三页，第二行。" |

核心方法：①用行为代替形容词 ②用细节代替总结 ③用对话代替旁白 ④用反应代替情绪词。

## 十二、改写范例库

### 情绪外化范例
| 情绪 | AI写法 | 自然写法 |
|------|--------|----------|
| 紧张 | 他感到一阵紧张，心跳不由自主地加快了 | 他攥紧了手里的纸杯，水洒出来一些 |
| 愤怒 | 愤怒在他心中燃烧，他不由得握紧了拳头 | 他把筷子往桌上一拍，碗里的汤溅了出来 |
| 悲伤 | 一丝悲伤涌上心头，她的眼中闪过泪光 | 她低头搅着咖啡，搅了很久 |
| 害怕 | 恐惧瞬间笼罩了他，他感到一阵战栗 | 他的背贴在墙上，不敢动 |
| 失望 | 她感到一丝失落，心仿佛被什么东西揪住了 | "哦。"她把手机锁了屏 |
| 惊讶 | 他的瞳孔微微收缩，显然没有想到会听到这样的话 | 他张了张嘴，什么都没说出来 |

### 场景/天气/打斗改写
- AI场景："阳光透过窗帘的缝隙洒进来，在地板上投下斑驳的光影……" → 下午三点，客厅里只有钟在走。
- AI天气："天空阴沉沉的，乌云密布，仿佛随时都会下起倾盆大雨……" → 要下雨了。风把晾在外面的衣服吹得乱晃。
- AI打斗："他的拳头犹如疾风骤雨般猛烈，每一击都蕴含着不容置疑的力量……" → 他一拳怼过去，对方没躲开，嘴角破了。

### 结尾改写
- 升华式结尾："他站在窗前，望着远方的天际线，终于明白了生活的真谛……" → 他把烟掐了，回屋睡觉。
- 总结式结尾："这一刻，一切都变了。她知道，从今以后……" → 她关上了那扇门。没回头。
- 感慨式结尾："岁月如流水般悄然流逝……" → 直接删掉。

### 节奏调整
- 排比："他看着她的眼睛，看着她的嘴唇，看着她微微颤动的睫毛……" → 他看着她。她没说话。
- 长句拆短："当他终于推开那扇沉重的木门时，映入眼帘的是……" → 门开了。屋里很暗，角落堆着几个箱子，上头全是灰。

### 冲突对话改写
- AI式温和："我觉得你这样做不太合适，能不能考虑一下我的感受？" → "你眼里还有我吗？"
- AI式完美解释："其实我这样做是有原因的，因为当时的情况非常复杂……" → "你能怎么着？"她把茶杯重重放下。

### 对话情绪五级递进（冲突场景从弱到强）
1. 客观陈述："你把我的东西扔了。"
2. 陈述+建议："你把我的东西扔了，以后能不能先跟我说一声。"
3. 主观指责："你凭什么动我的东西。"
4. 指责+命令："你算什么东西，也配碰我的东西？滚出去。"
5. 指责+PUA："我伺候你吃伺候你穿，你连个东西都放不好。你这辈子也就是这样了，离了我你什么都不是。"

### 震惊分层（禁止一步到位）
AI式："所有人都震惊了，不敢相信自己的耳朵。"
自然分层：① 对面男人的手抖了一下，茶杯里的水洒出来。② 旁边的人互相看了一眼，有人往后退了一步，角落里有人开始掏手机。③ 刚才还趾高气扬的女人，脸上的笑僵住了，张了张嘴，一个字没说出来。

### 代入感修复
被动主角："她很害怕，不知道该怎么办，只能等着事情过去。"
主动主角："她锁了门，把手机调成静音，打开了录音。"

## 十三、格式与叙事红线（rules 层）

**正文格式硬规**：
1. 段落按戏剧单元/镜头/一件事结束自然断开；不按固定字数强拆，也不把多个动作、线索、视线切换塞进一段
2. 正文相邻段落间只允许一个换行符 `\n`，不得出现空行或 `\n\n`
3. 禁止「他说」「她道」标签，对话用动作引出或独立成行
4. 禁止大段描写堆砌，描写穿插动作或对话，不连续超3段纯描写
5. 禁止跳出视角：锁死主视角后不切他人内心（深度限知）
6. 禁止主语过密：同一动作链内不要连续句/段无必要重复同一主角名；段首点名，段中用代词/省略承接，关键转折再点名
7. 正文禁用破折号 `——`/`—`、双连字符 `--`、省略号停顿 `……`（用句号、逗号、短句、动作断句），不设对话例外
8. 标题行以外不得出现写作元信息词：`第X章|上一章|上章|前一章|本章|这一章|前文|后文|伏笔|细纲|读者`；需要承接前文改成角色能感知的事件锚点或相对时间

**叙事红线（AI腔禁令）**：
1. 禁止章末总结/升华/哲理收尾（"他终于明白了……""这一夜注定无人入眠"）
2. 禁止"他感到/觉得"直述情绪，用身体反应替代（"手心全是汗" > "他很紧张"）
3. 禁止连续2段以上纯心理活动，必须穿插动作/对话
4. 禁止万能比喻（"像潮水般""如闪电般"），要么不用要么生活化
5. 禁止所有角色说话方式一样，每个角色必须有独立语言风格
6. 对话三功能检验：每段对话删掉后检查——情节还能推进吗？期待感还在吗？情绪还到位吗？三项全否 = 水字数，删。

## 十四、质量检查清单（写完每章逐项扫）

**语言与AI指纹**：
- [ ] 正文无破折号/省略号停顿（含叙述和对话）
- [ ] 无AI高频词：不禁/仿佛/映入眼帘/心中暗道/沉声道/嘴角微扬/不由自主/只见
- [ ] 弱化副词：每千字"微微/淡淡/缓缓/轻轻"≤3个
- [ ] 无三连排比、无"不是A而是B"翻转句式
- [ ] 无论文体："不难看出/由此可见/事实上/综上所述"
- [ ] 无书面语连词堆砌："于是乎/与此同时/从而/因而/诚然"
- [ ] 章尾无总结升华（用动作/对话/悬念收束）
- [ ] 无大段心理描写（心理活动≤2段，无括号标注内心）
- [ ] 情绪用动作展示，无直接写"愤怒/伤心/紧张"
- [ ] 对话口语化，无书面腔，不同角色语气可区分
- [ ] 标点不压平：质问/爆发/犹豫不用句号硬压，也不用随机 `？`/`！` 或 `……`/`——` 硬造停顿
- [ ] Show Don't Tell：用行为代替形容词，用细节代替总结
- [ ] 句长匹配场景：打斗冲突段更短，朗读不卡、信息不过载
- [ ] 身体部位同一词全文 ≤5 次
- [ ] 无正文元信息污染（章号/上一章/伏笔/细纲/读者等词）

**结构与节奏**：
- [ ] 开头有钩子（不是天气/风景/日常开场）
- [ ] 中段有推进，局势有变化（读完这章世界跟之前不一样了）
- [ ] 结尾落在变化上，有危机/决定/发现/反转至少一个，不是总结
- [ ] 没有可删除的段落（删掉这章会影响理解吗？不会 = 水了）
- [ ] 没有大段设定说明文（一章新概念≤3个）
- [ ] 人物在做事情，不是在感觉事情
- [ ] 场景有目标/阻碍/变化三要素
- [ ] 无连续多段同一情绪

## 十五、AI味打分客观指标（分级依据）

| 指标 | 计算方式 | 轻度 | 中度 | 重度 |
|------|----------|------|------|------|
| 禁用词密度 | 命中次数/千字 | ≤5 | 6-15 | >15 |
| 连续排比段数 | 连续同构句式段落数 | ≤2 | 3-4 | ≥5 |
| 心理词占比 | 直接心理描写词数/总段落数 | ≤10% | 10-25% | >25% |
| 对话标签密度 | "说道/问道/笑道"等/对话句数 | ≤30% | 30-50% | >50% |
| 平均段落句数 | 总句数/总段落数 | ≤3 | 3-5 | >5 |
| 重复描写密度 | 同一信息/动作/情绪连续多段拆写处数/千字 | ≤1 | 2-3 | ≥4 |

综合判定：取六项最高档。轻度只过 Gate A+B；中度过 A+B+C+D+G；重度完整 7 Gate+重点段落重写。
删除比例上限：轻度 ≤15%，中度 ≤25%，重度 ≤35%；不得整段删正文，删前确认不丢伏笔/钩子/角色/情节。

## 十六、可直接粘贴的提示词模板

### 模板 A：检测（只报告不改）
> 你是网文 AI 味审稿人。检测以下文本，只报告不修改：
> 1. 按 8 种 AI 写作模式逐项扫：AI高频词、弱化副词（微微/淡淡/缓缓/轻轻每千字>3）、意义膨胀、万能结论、论文体开头（不难看出/由此可见）、书面语连词、三连排比、解释腔/上帝感（之所以/原来/她不知道的是/殊不知/演得真好）
> 2. 按禁用词表扫：仿佛/犹如/一丝/一抹/不禁/眼中闪过/嘴角勾起/心头一震/不容置疑 等
> 3. 检查最毒句式："不是A而是B"翻转、"…，带着…"、声音描写、"他/她知道"
> 4. 检查章末是否总结/升华/预告
> 5. 输出格式：分级（轻/中/重）+ 逐处表格（位置/Gate/原文/问题/改法）。只报告，不修改原文。

### 模板 B：去AI味改稿
> 你是网文润色专家。把以下文本的 AI 味改写自然，遵守：
> 1. 改最少效果最大：能改一词不改一句，能删一句不重写一段；人名/地名/数字/专名保留
> 2. 只改"怎么说"不改"说什么"：不新增原文没有的情节、设定、关系、时间线；删除前确认不丢伏笔/钩子/角色特征/情节推进，删除比例≤25%
> 3. 按 7 Gate 执行：A禁用词替换（禁用词→具体动作，不换另一个形容词）；B句式去套路（最毒翻转句式直接写后项；修饰词清扫）；C心理外化+重复描写合并+重复语义去重；D节奏打碎（长短交错、疏密有别，不机械拆短）；E对话去腔调（口语化、差异化、删解释性对话）；F结尾去升华（动作收尾）；G去解释腔/上帝感/安排感
> 4. 不保留 `……`/`——`（改用句号/逗号/动作/短句），保留有功能的 `？` 和少量 `！`
> 5. 输出：修改统计 + 逐处前后对比 + 润色后全文。

### 模板 C：写正文自带反AI约束
> 写作时遵守以下硬约束：
> 1. 情绪用身体反应展示，不写"他感到/他觉得"
> 2. 禁"不是A而是B"翻转句式、禁三连排比（砍到1条）、禁万能比喻、禁"…，带着…"
> 3. 心理活动≤2段，穿插动作/对话；描写不连续超3段
> 4. 对话口语化、每角色语气可区分、删解释性对话
> 5. 章尾用动作/对话/悬念收束，禁止总结升华哲理预告
> 6. 段落按戏剧单元断开，长短交错，正文无 `……`/`——`/破折号/空行
> 7. 深度限知视角：只写角色此刻看到听到闻到的，不剧透、不解释、不定性
